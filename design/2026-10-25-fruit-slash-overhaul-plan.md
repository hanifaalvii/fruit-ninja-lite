# Fruit Slash Overhaul Implementation Plan

**Goal:** Turn Fruit Slash (pygame + pygbag, `/Users/hanifa/Documents/GitHub/fruit-ninja-lite`) into a polished, 3D-looking, smooth, content-rich browser game for phone + laptop, with an interactive loading screen, real music/SFX and deeper gameplay.

**Spec:** `fruit-ninja-lite/design/2026-10-25-fruit-slash-overhaul-design.md` (approved).

**Architecture:** Split 1301-line `main.py` into a `game/` package. Pure-logic modules (scoring, modes, progress) are headless-testable; rendering is cached once at load so frames only blit; assets in `assets/` (CC0/permissive OGG + PNG, credited) with synthesized fallbacks; an adaptive quality governor sheds effects before frames drop.

**Global constraints:** 4 modes kept; leaderboard/`config.py` unchanged; 60 FPS target (p95 < 16.7 ms headless); no per-pixel loops per frame; particle cap 120 desktop / 60 web; logic res 1000x650, mouse+touch; old saves must load; `docs/` generated by `deploy.sh` only.

**Review focus:** old saves lacking new keys; missing assets / no audio device; dt spikes; offline leaderboard never blocks; multi-touch/resize/rotation.

## Tasks (TDD, commit after each)
1. **Baseline + package split + test harness**: smoke test first on untouched code; move code into `game/` modules (settings, progress, net, ui, entities, audio, sprites); `ARCHITECTURE.md`; old-save defaults test.
2. **Pure logic**: `scoring` (Combo x1-x5, swipe_bonus, PowerUps slowmo/double/rain), `modes.WaveDirector` (boss every 8th Classic wave, Zen no bombs), difficulty table (easy/normal/hard).
3. **Progress**: 12 achievements, unlocks (blades, backgrounds), deterministic daily challenge.
4. **Assets + audio**: staged async `Loader` (failure-tolerant), `Audio` manager (files with synth fallback, ducking, 3 music tracks, fruit-specific SFX), `tools/fetch_assets.py`, `assets/CREDITS.md`, licence verification.
5. **3D-look sprites**: shaded spheres, specular/rim light, 24 cached rotations, shadows, juicy halves, boss, power-ups, parallax background layers.
6. **Effects**: Quality governor, capped particles, shake, slow-mo, persistent splats, glow blade trail, clamped physics dt.
7. **Scenes**: interactive loading (slice fruit to fill bar, tips, tap-to-start audio gate), animated menu (tilting mode cards, difficulty, daily, achievements, unlocks, settings, leaderboard panel), gameplay integration (combos, power-ups, boss, bomb shake/slow-mo/duck, HUD, game over + unlock toasts), single-pointer touch handling.
8. **Performance**: headless p95 frame-time test, profile and fix hot spots.
9. **Web build + docs**: `sh deploy.sh`, Playwright check on desktop and phone-landscape viewports (no console errors, screenshots reviewed), README update, final fresh review; ask before pushing to Pages.

Full detail (test code, interfaces) is in the design folder once writes are allowed.

**Risk:** environment Python 3.15 vs pygbag's bundled CPython; verified in task 9.
